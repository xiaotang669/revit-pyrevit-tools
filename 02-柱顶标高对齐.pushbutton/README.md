# 柱顶标高批量驱动 / Column Top Elevation Align

Revit 2020 + pyRevit + IronPython 2.7 脚本。输入绝对标高，一键将选中的结构柱顶部精准对齐（专治异形屋面）。

---

## 功能 / Features

- **绝对标高驱动**：无论柱底在哪一层，输入目标绝对高度（如 10.32m），柱顶瞬间齐平。
- **智能双重驱动**：自动识别柱子是“顶部约束”还是“无连接高度”，采用不同的参数计算方式，防止标高错位。
- **毫米级复核**：修改后自动回读实际标高，偏差超过 0.1mm 直接报错跳过，绝不假成功。

---

## 使用方法 / Usage

1. **选中柱子**：在视图中选中需要对齐的结构柱。
2. **输入标高**：点击按钮，在弹出的对话框中输入目标顶标高（单位：米，例如 `10.32` 或 `10.32m`）。
3. **自动处理**：脚本自动修改顶部偏移并强制刷新几何，弹窗报告成功数量。

---

## 常用配置 / Configuration

在 `script.py` 顶部修改：
- 无特殊配置，直接使用即可。脚本内置了 `MIN_HEIGHT_FT = 10mm` 的安全限制，如果输入标高导致柱高低于 10mm，会自动跳过防止报错。

---

## 已知限制 / Known Limitations

1. **仅支持结构柱**：建筑柱、常规模型无法处理。
2. **不处理底部约束**：脚本只负责拉伸顶部达到绝对高度，不会修改柱子底部的标高约束。
3. **不处理链接模型**：当前版本的柱子必须在当前的主模型中，不支持直接选中链接模型里的柱。
