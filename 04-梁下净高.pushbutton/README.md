# 梁下净高查看 / 标注 / Beam Clearance

Revit 2020 + pyRevit + IronPython 2.7 脚本。专为机电工程师打造，支持在机电模型中直接跨链接读取土建梁和楼板，一键计算梁底净高，并可生成或更新文字标注。

---

## 功能 / Features

- **跨链接模型读取**：完美解决机电、土建分模型的问题。直接读取“土建链接模型”里的梁和楼板，自动进行底层坐标转换，精准计算净高。
- **智能兜底**：优先读取下方楼板；如果没有楼板，自动使用当前视图的关联标高（`GenLevel`）兜底，防止算不出结果。
- **防重叠更新**：再次运行脚本时，自动寻找附近的旧标注并**直接更新文字数值**，绝不会重复生成一堆重叠的文字把图纸搞乱。
- **主次梁通吃**：自动识别项目中所有的结构梁（包含主梁和次梁）。

---

## 使用方法 / Usage

1. **选中构件**：
   - 如果梁在当前模型，直接框选。
   - 如果梁在土建链接模型，**无法框选**。请先选中当前模型的任意图元，运行脚本后，根据提示在链接模型中**连续点选**梁，按 `Enter` 结束。
2. **选择模式**：点击按钮后，弹出选项窗口：
   - `仅弹窗查看结果`：在输出窗口生成表格，不改动模型。
   - `生成/更新文字标注并查看`：在梁中心生成文字，如果有旧文字则直接更新。
3. **文字避让**：如果文字压住了梁或者互相重叠，去代码顶部修改 `TEXT_OFFSET_DOWN_MM = 0.0`，把数值改大（如 300），文字会自动往下挪。

## 常用配置 / Configuration

在 `script.py` 顶部修改：

- `INCLUDE_LINKED_SURFACES = True`：是否搜索链接模型里的楼板/吊顶（机电模型必开）。
- `UPDATE_EXISTING_TEXT = True`：是否开启更新已有文字功能。
- `MATCH_DIST_MM = 1000.0`：新旧文字多近才算同一个标注。如果旧标注离梁太远无法更新，可以调大这个值。
- `TEXT_Z_MODE = "VIEW_LEVEL"`：文字放置高度。默认跟随视图标高（相当于放在楼面上）。

## 已知限制 / Known Limitations

1. **不支持嵌套链接**：链接里面再嵌套的链接模型不会被搜索。
2. **不扣面层厚度**：楼板高度直接取 `BoundingBox.Max.Z`（结构板顶）。如果需要建筑完成面净高，请自行扣除面层厚度。
3. **斜梁取最低点**：倾斜的梁只取最低点算一个值，不会沿梁长显示连续变化的净高。
4. **兜底可能导致数值偏小**：如果没有楼板，代码会用当前视图标高计算。如果你的视图标高和梁在同一层，算出的净高可能会接近 0 甚至负数（此时输出表格里会标注“视图标高”提醒你复核）。
