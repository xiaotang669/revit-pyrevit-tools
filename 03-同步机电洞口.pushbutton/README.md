# 同步机电洞口 / Sync MEP Openings

Revit 2020 + pyRevit + IronPython 2.7 脚本。机电管线（风管 / 水管 / 桥架）移动后，一键把对应的墙 / 楼板洞口移到管线的当前位置。

---

## 功能 / Features

- **一键纠偏**：无视管线怎么移动，框选后一键让洞口重新跟随管线中心。
- **支持链接模型**：完美解决“土建在链接，机电在当前模型”导致的坐标错位问题。
- **极强容错**：支持原生洞口、基于面的洞口族，自动排除门窗等误选图元。
- **防崩设计**：独立子事务，一个洞口失败不影响其他；自动静默 Revit 警告弹窗。

---

## 使用方法 / Usage

1. **框选图元**：框选已移动的管线，以及需要同步的洞口。
2. **选择链接（重要！）**：如果墙/楼板在链接模型里，**必须按住 `Ctrl` 键，点选一下那个链接模型实例**，否则脚本找不到宿主！
3. **运行脚本**：点击本按钮，脚本计算后弹窗报告结果。
4. **安全模式**：首次使用，强烈建议先在代码顶部把 `DRY_RUN` 改为 `True`，看输出窗口的匹配对不对，确认无误后再改回 `False` 正式移动。

---

## 常用配置 / Configuration

在 `script.py` 顶部修改：

- `DRY_RUN = False`：试运行模式，只算不移。
- `MAX_MATCH_DIST_MM = 1000.0`：管线与洞口的最大匹配距离。如果你的洞口偏移太远匹配不上，可以加大到 3000。
- `ALLOW_LINKED_MOVE_ATTEMPT = False`：Revit API 不允许移动链接里的元素。如果要处理链接里的洞口，请在土建模型中运行。

---

## 已知限制 / Known Limitations

1. **链接模型只读**：洞口本身如果在链接模型里，脚本只能计算出正确的位移值（输出在窗口里），无法直接帮你移动。请切换到土建主模型运行。
2. **原生草图洞口**：如果是用“草图”画的楼板洞口，Revit API 常常会拒绝移动，脚本会跳过并报错。
3. **标注信息不更新**：脚本只负责移动三维洞口模型，如果您用第三方插件（如品茗）打的尺寸标注，需要您手动刷新或利用原插件更新。
4. **匹配歧义**：如果两根管线离同一个洞口极近，脚本会默认匹配最近的那根。位移超过 300mm 的洞口会在报告中标 ⚠️，请人工复核。
